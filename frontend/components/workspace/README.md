# Modul Workspace EPIONA

Direktori ini menampung antarmuka interaksi ruang kerja riset akademik EPIONA.

## Komponen:
1. `WorkspaceView.tsx`: Wrapper utama area workspace chat, header navigasi, transisi layout Hero ke Stream, dan kontrol split-pane.
2. `SourcesAccordionPopover.tsx`: Popover drop-down modern ala Perplexity yang mengelompokkan sitasi berdasarkan Web (PubMed/jurnal) dan Files (MyLibrary).
3. `EvidenceViewerPanel.tsx`: Panel kanan viewer ganda (Academic Evidence Viewer dengan DOI/abstrak dan Adobe PDF reader bawaan browser).
